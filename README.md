# Fire-and-Gas-Leakage-Monitoring-and-Warning-System
Designed to develop an IoT safety monitoring system for early risk detection, with low cost and easy residential deployment. It uses ESP32 and environmental sensors to process real-time data, supports remote monitoring, and aims to integrate machine learning for better alerts.
